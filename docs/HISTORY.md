## 1. 미결정 (결정 필요)

### 1-1. 옷장 · 옷 가게
- [미정] 시작 보유 옷: 현재 코드는 25벌 전부(`STARTS_OWNED`) / [제안] 6벌(비니·안경·후드티·보따리·커피·슬리퍼). 시안 TURN 28·30 모두 6벌 기준(샘플 코인 680, 흥 42). 코드 요청은 6벌로 작성
- [제안] 옷 가격표: 판매 19벌 합계 6,100코인 (월급 Lv1 100 기준, 레벨 올라도 가격 고정)
- [미정] 놀기 포즈의 풍선 소품과 옷장 손 슬롯 풍선 아이템의 관계
- [제안] 마을 배경 6종 가격 1,500코인(시안 샘플), 기본은 무료. 월급 Lv1 100 기준 15일 치
- [제안] 배경 테마: 기본 = 지금의 낮·밤 자동 전환, 구매한 배경은 시간과 상관없이 고정 팔레트. 시안에는 테마당 6색(하늘·풀·흙·물·물결·나무)과 장식 점만 있어 메인 장면 층별 팔레트는 Claude Code가 파생 → 결과 확인 필요
- [미정] 꾸미기에서 뺀 마을 소품(건물)·이장 스킨을 다시 넣을지(사용자 10-30: 나중에 재고). 그때까지 이장·마을 건물 스킨은 기존 작물 교환소로만 얻음
- [확인 필요] 시안 TURN 31 수확 창고(31e·f)는 교환소를 없애고 작물을 개당 100코인(샘플)에 파는 화면. 사용자 요청 목록에 없어 코드 요청에서 제외, 기존 교환소 유지. 채택 여부는 코인 경제(월급·가격)와 같이 결정
- [미정] 메인 솔이 표정(지침/보통/신남): 옷 합성 에셋은 기본 포즈 하나뿐이라 옷을 입힌 메인 솔이는 표정 변화 없음. 필요하면 표정별 기본 포즈를 Claude Design에 요청

### 1-2. 재화 · 보상 (코인 · 흥)
- [미정] "쉬는 날에만 흥" 해석: 현재는 놀기를 고른 날로 처리 중. 다른 뜻이면 수정
- [제안] 자동 감소 없음 (일한 날 흥 감소·놀기 날 코인 감소 없음, 쓸 때만 줄어듦). 사용자 최종 확인 안 받음
- [제안] 흥 상한·만료 없음. 많이 쌓였을 때 연출이나 상한 필요 여부는 미정
- [제안] 흥과 쉼 지수는 따로 둔다. 쉼 지수 솔이 표현(체력/활기)의 값도 미정
- [미정] 쉼 기록으로 흥을 줄지 (지금은 놀기 날만). 2주 실사용 후 재검토
- [미정] 월급 식 (임시: 100 + (마을 Lv−1) × 10)
- [미정] 코인·흥 지급 시점(저녁 기록 저장), 미지급 봉투 유지, 당일 수정 반영 — 데이터 모델 미설계
- [제안] 아침 선택(일/놀기)과 저녁 기록 시트의 일한 날/쉬는 날이 다를 때: 저녁 시트가 아침 선택을 기본값으로 채우고 수정 가능, 지급은 최종 저장값 기준. 확정 아님
- [미정] 아침 선택을 건너뛴("나중에 할래유") 날의 보상: 저녁 기록에서 고르게 할지, 없는지
- [가안 2026-10-30, 확정 아님] 지급량은 마을 레벨에 따라 달라짐(확정, 3장). 많이 줄 필요 없음(사용자). 식은 마을 레벨 상승 곡선(경험치)과 같이 보고 확정 → 그때까지 코드 상수 + TODO
  - 코인(월급): 100 + (마을 Lv − 1) × 10 (사용자 가안. Lv1 100, Lv7 160, Lv12 210). 기존 임시값과 같음
  - 흥: 10 + 2 × floor(마을 Lv ÷ 5) (Lv1~4 → 10, Lv5~9 → 12, Lv10~14 → 14). 사용자는 흥 식을 따로 말하지 않았고, 기존 시안·SPEC 18의 값을 그대로 둔 것임 (확인 필요)
  - 점검: 평상 간식 나눔이 흥 10이라 Lv1에서 놀기 하루 = 행사 1번. 행사 비용(1-4)과 같이 균형 확인 필요
- [충돌, 확인 필요] 시안 TURN 29 "오늘 하루 v6"은 놀기 보상을 "흥 +10 (레벨과 상관없이 고정)"으로 그리고 보상표 진입을 뺐음. 사용자가 10-30에 한 말(레벨별 지급)과 다름. 코드 요청은 사용자 발언(레벨 연동 식)을 따르고 v6은 레이아웃만 따름. 고정이 맞으면 `PLAY_HEUNG_STEP`을 0으로

### 1-3. 마을 레벨 · 수확 레벨
- [미정] 레벨 구조 정리 (수확 레벨 vs 마을 레벨, 인수인계 4-A). 이게 정리돼야 월급 곡선과 해금 숫자를 조정할 수 있음
- [제안] 마을 경험치 = 기록한 날 수(하루 1). 영역별 +5 제거 (기록 부풀리기 방지). 현재 코드(기록 +10, 영역 +5)와 다름
- [제안] 마을 부제가 레벨에 따라 바뀜 (아직 망하진 않음 → 생각보다 버팀 → 소문 좀 남 → 이장도 놀람)
- [미정] 수확 레벨: 5개마다 1레벨 + 레벨마다 교환소에 스킨 진열 (제안). 현재 코드는 15개마다
- [미정] 농부 칭호 체계 vs 솔이 칭호 "야근을 견딘 새싹"(상태 기반 별도 체계인지)

### 1-5. 메인 · 방송 · 장면
- [사용자 확인 2026-10-30] 메인 장면에서 게시판·이웃이 사라진 건 의도가 아님 → 복원 요청(3장). 지수 카드는 언급 없음(메인에서 빠진 채 나 탭 "최근 4주"로 봄). 집·냇가·날씨 표현도 같이 복원 요청에 포함. 시안에는 복원 위치가 없어 Claude Code가 원칙대로 배치하고 스크린샷으로 확인 → 위치가 마음에 안 들면 Claude Design에 배치 시안 요청
- [제안] 하루별 장면 판단: 행사 당일 → 여행 장면 / 일한 날 + 근무 시간대 → 출근 장면 / 쉬는 날·주말 → 쉬는 날 장면 / 그 외 → 기본. 시안 v12는 기본(밤)·낮 두 장면만 쓰고, 일·여행·쉼 변형은 시안 코드에 있으나 연결하지 않음. 원경과 솔이 소품만 바꾸고 밭·날씨는 유지
- [미정] 이장 방송에서 오늘 일정·전날 보고 방식
- [미정] 꾸역 이장 츤데레 규칙(첫 문장 무심, 끝에 챙김, 시니컬 7 : 따뜻함 3, 행동으로 따뜻함, 두 문장 이내) 적용 여부
- [미정] VOICE.md 미작성 (저장소에 없음). 폭풍 문구 정리: "...오늘은 방송 안 혀유. 마을은 이장이 볼 테니께 푹 쉬어유." [제안]

## 3. 2026-10-30 기준 "확정"이지만 정본 미반영

> 정본(SPEC/CLAUDE.md)에 반영하면 이 칸의 항목은 삭제한다.

- 재화 3종: 작물(기록 보상) / 코인(일 선택한 날 월급, 저녁 기록 저장 시 지급, 솔이 옷 구매) / 흥(놀기 선택한 날 획득, 마을 행사용)
- 코인과 흥의 지급량은 마을 레벨에 따라 달라짐 (2026-10-30 사용자 확인). 진행현황의 "흥 +10 고정"은 이 확인으로 폐기
- 작물은 이장·마을 건물 스킨 구매 유지. 코인은 옷 구매에만 쓴다
- 흥 10으로 열 수 있는 기본 행사 1개 추가 (평상 간식 나눔, Lv1)
- 행사는 그날 하루(다음 04시까지) 연출, 끝나면 행사 앨범에 영구 기록. 확률 보상 없음
- 코인 칸 누르면 옷장, 흥 칸 누르면 마을 행사 (시안 TURN 30)
- 솔이 옷장은 아침 흐름에서 빼고, 탭 없이 여는 전체 화면으로 만듦. 하단 탭은 5개(장부·이웃·마을·쉼터·나), 마을이 가운데. 진입점: 메인 코인 칸 · 솔이 탭 · 나 탭 "솔이 옷장" 줄 (시안 TURN 30, 6탭 안은 폐기)
- 옷장 UI (시안 TURN 30 v2): 내 옷장/옷 가게 구분 없이 한 목록(시작 옷 → 가격 오름차순), 미보유는 흑백 60%, 칸 선택 시 미리보기(여러 슬롯 가능, "원래대로"), 하단 버튼 구매하기 · 갈아입기 · 착용 중/벗기, 구매 확인 시트 없음, 코인 부족은 경고색 없이 비활성 버튼 "코인이 모자라요 · -N"
- 메인 구조 (시안 TURN 30 v12): 장면이 화면 전체, 반투명 HUD(좌: 마을 이름·Lv·XP / 우: 코인|흥 알약), 솔이 1.4배, 방송띠 접기/펴기(기본 접힘), 밭은 장면 속, 오늘 기록하기 버튼 유지. 지수 카드 · 게시판 · 놀러 온 이웃 · 집 · 냇가 · 4:3 비율 규칙은 메인에서 빠짐 (1-5 확인 필요)
- 꾸미기 (시안 TURN 31, 사용자 10-30): 옷장을 "꾸미기"로 넓힘. [솔이 | 마을] 구분, 마을은 **배경만**(소품·이장은 시안에서 빼고 나중에 재고). 배경을 사면 메인 마을에 바로 적용되고, 꾸미기 마을 미리보기는 메인 장면과 같은 장면을 씀(현재 배경 = 기본)
- 옷을 갈아입으면 메인 솔이에 그대로 반영 (메인·나 탭 프로필·꾸미기 미리보기가 같은 합성 사용)
- 메인 솔이 크기는 시안 v12(1.9배)가 너무 큼 → v11 크기(1.364배)로 되돌림, 상수 한 곳
- 하루 고르기 (시안 TURN 29 v6): 진행 표시는 체크(아침) · 발자국 · 깃발, 보상표 진입 버튼 제거
