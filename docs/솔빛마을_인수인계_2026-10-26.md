## 1. 컨셉 (확정)

**한 줄:** 내 삶을 기록하면 화면 속 시골 마을이 따라 변한다. 게임이 나를 성장시키는 게 아니라, **마을이 내 삶을 옆에서 보조**한다.

**핵심 원칙**
1. **지수는 날씨, 레벨은 땅.** 지수는 매일 오르내리고, 레벨과 보유 작물은 절대 줄지 않는다.
2. **솔이(나)에게는 레벨이 없다.** 레벨은 마을과 수확에만 있다.
3. **기록은 정확해야 한다.** 희귀·확률 보상 없음. 하루 기록 1번 = 씨앗 1개.
4. **벌이 없다.** 안 해도 시들거나 잃는 것 없음. 돌봄 의무 없음.
5. **관계는 긍정적으로.** 가까운 이웃을 부각하고, 소홀한 이웃을 경고하지 않는다.
6. **한자 금지.** 한글·영문만 사용한다.

**톤:** 동글동글 귀여운 그림 + B급 시니컬. 다크 남색 배경에 형광 핑크·노랑 포인트.

**등장인물**
- **솔이:** 나. 새싹 머리 주민. 컨디션에 따라 지침 / 보통 / 신남
- **꾸역 이장:** 모든 알림을 "마을 방송"으로 전달하는 해설자. **충청도 사투리 + 시니컬 + 은근한 따뜻함(츤데레)**
- **이웃:** 내가 등록한 실제 사람들 (얼굴 12종 + 배경색 6종)

**4개 영역**

| 영역 | 입력 | 마을 속 모습 |
|---|---|---|
| 건강 | 컨디션 3단계 | 하늘과 날씨 (5단계) |
| 일 | 일 강도 1~3, 성취 한 줄 | 밭 + 야근 등불, 성취는 장부로 |
| 관계 | 누구와 + 방식 | 가까운 이웃이 솔이 곁에 등장 |
| 쉼 (구 여가) | 쉼 칩, 장작 던지기 | 모닥불 (쉼터 탭) |

다루지 않는 것: 돈·가계부, 칼로리, 할 일 관리, 몬스터 전투, 희귀 아이템, 로그인(현재).

**하단 탭 5개:** 마을 / 장부 / 이웃 / 쉼터 / 나

## 4. 남은 결정과 불일치 (다음 작업 전에 정리할 것)

### A. 레벨 구조 — 논의했지만 코드에 반영되지 않음
- **지금 코드:** 마을 경험치 = 기록 +10, 영역 입력마다 +5 / 곡선 30+20×(L−1). 수확 레벨 = 15개마다 1레벨. 스킨 일부만 수확 Lv.6/8/10 잠금.
- **10-21에 논의한 안 (확정 전):**
  - 자동 수확 이후 **수확 수 = 기록한 날 수**가 되어 두 레벨이 같은 걸 세는 문제가 있음
  - 수확 레벨: 5개마다 1레벨, 레벨마다 교환소에 스킨이 **진열**됨, 농부 칭호
  - 마을 레벨: 경험치 = 기록한 날 수(하루 1). 영역별 +5 제거(많이 적을수록 점수가 오르면 기록을 부풀리고 싶어짐). Lv.10 ≈ 63일. **마을 부제가 레벨에 따라 바뀜**: 아직 망하진 않음 → 생각보다 버팀 → 소문 좀 남 → 이장도 놀람
- 스킨이 20종으로 바뀌었으니 진열 순서는 다시 짜야 함

### B. v9 상태창(16e)과 규칙 충돌
- 시안의 상태창에 **솔이 옆 "Lv.7"** 표시 → 규칙 2(솔이에게 레벨 없음)와 충돌. 마을 Lv로 바꾸거나 빼야 함
- **새 칭호 "야근을 견딘 새싹"**: 농부 칭호와 별개의 새 칭호 체계인지, 상태(지수) 기반 칭호인지 정의 필요
- SPEC 11장 "솔이 탭 = 반응과 한마디(기능 없음)" → "반응 후 상태창"으로 수정 필요
- **하루별 장면 판단 규칙 (제안):** 대소사에 오늘 여행 → 여행 장면 / 기록 "일한 날" + 근무 시간대 → 출근 장면 / "쉬는 날" 또는 주말 → 쉬는 날 장면 / 그 외 → 기본. 원경과 솔이 소품만 바꾸고 밭·게시판·날씨는 유지
- 장면은 층별 컴포넌트(원경 / 날씨 / 중경 / 마당 / 전경)로 분리. 애니메이션은 지금 설치된 reanimated + SVG로 충분

### C. 이장 말투 — 츤데레 규칙 미반영
- `docs/VOICE.md`가 저장소에 없음 (SPEC 15장에도 "VOICE.md가 없어 시안 문구 사용"이라고 적혀 있음)
- 규칙: 첫 문장은 무심하게, 끝에 슬쩍 챙기기(시니컬 7 : 따뜻함 3). 따뜻함은 행동으로("등불은 이장이 꺼놓을 테니께"), 직접 위로 금지. 어미 위주 사투리, 두 문장 이내. 폭풍인 날은 따뜻함만
- 폭풍 문구가 아직 "...오늘은 방송 안 해유. 푹 쉬슈. **이상.**" → 제안: "...오늘은 방송 안 혀유. 마을은 이장이 볼 테니께 푹 쉬어유."
- 기준 문구 예시 (10-22 정리)

| 상황 | 문구 |
|---|---|
| 아침 흐림 | 오늘 날씨 흐려유. 솔이 씨 얼굴도 흐리구. 우산은 문 앞에 둬놨슈. |
| 일 과열 | 밭에 또 밤새 불 켜놨네유. 등불은 이장이 꺼놓을 테니께 들어가 자유. |
| 이웃 방문 | 하준 씨 또 왔슈. 문지방 닳겄어유. 그래도 오는 사람 있는 게 복이여유. |
| 쉼 부족 | 냇가 물이 탁허네유. 이장이 정자 닦아놨으니께 좀 앉았다 가유. |
| 기록만 한 날 | 별일 읎는 날이네유. 그런 날도 적어두면 다 쓸모 있슈. |
| 자동 수확 | 밤새 딸기 따서 창고에 넣어놨슈. 젤 잘 익은 건 맨 위에 올려놨구유. |
| 행사 전날 | 낼이 엄마 생신이여유. 빈손으로 가지 말구, 전화라도 한 통 드려유. |
| 장부 | 장부에 다 적어놨슈. 솔이 씨가 까먹어도 이장은 안 까먹어유. |
| 지침 신호 | 일은 닷새째 갈려나가구, 쉼은 바닥이구, 하늘은 흐리구. 오늘은 이장 말 좀 들어유. |

- **확인:** Windows에서 `npx expo start` → 웹(`--web`) 또는 아이폰 Expo Go. 다른 네트워크면 `--tunnel`
  - App Store의 Expo Go는 SDK 버전 하나만 지원하므로 프로젝트 SDK와 맞춰야 함
- **iOS 빌드:** 맥이 없음
  - 지인 맥 + 무료 Apple ID → 7일마다 재설치 (`docs/BUILD-iOS.md`)
  - 또는 EAS Build(클라우드, 무료 플랜 iOS 빌드 15회) + 유료 Apple Developer(연 99달러) → TestFlight
- **웹 배포:** Netlify (`netlify.toml`, `build:web`). 웹은 알림 미지원, SQLite는 wasm 설정 사용
